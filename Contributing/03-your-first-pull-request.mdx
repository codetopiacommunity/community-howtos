# Your First Pull Request

A real pull request on our practice project, reviewed and merged. You
add one small file about yourself. About **ten minutes**, all in your
browser. Nothing to install.

> [!NOTE]
> Words you will see on screen:
>
> - **Repository** (repo): a project's folder of files on GitHub.
> - **Fork**: your own copy of a repo. Changing it cannot break the
>   original.
> - **Commit**: a saved change with a short note.
> - **Pull request** (PR): "here is my change, please review it."

---

## Before you start

You need a **GitHub account**, and you need to be signed in. Your
profile picture at the top right of any GitHub page means you are.

<a href="https://github.com/signup" target="_blank" rel="noopener noreferrer">🔗 Create a GitHub account</a>

---

## Step 1: Open the contributors folder

<a href="https://github.com/codetopiacommunity/open-source-practice/tree/main/contributors" target="_blank" rel="noopener noreferrer">🔗 Open the contributors folder</a>

You will see a `README.md` and one file for every person who has done
this before you.

## Step 2: Create your file

1. Click **Add file**, then **Create new file**.
2. GitHub says you are making changes in a project you don't have
   write access to. That is expected. It will make your own copy (a
   fork) for you when you save.
3. In the name box at the top, type your **GitHub username** followed
   by `.md`. For example: `kofi-mensah.md`.

> [!IMPORTANT]
> Use your GitHub username as the file name, not your real name. Two
> people can share a name, but never a username.

---

## Step 3: Write about yourself

In the big box, paste this and fill in the blanks:

```
# Your Name

- From: Your city, your country
- Learning right now: what you are learning
- Fun fact: one thing about you
```

Keep it short. Three lines is plenty.

{/* IMAGE NEEDED: images/Contributing/first-pr/new-file.png
    Show: the new file editor with the file name typed and the template
    filled in. Device: computer. */}

---

## Step 4: Save it

1. Click the green **Commit changes...** button at the top right.
2. In **Commit message**, write what you did: `Add kofi-mensah to
   contributors`, using your username.
3. Click **Propose changes**.

---

## Step 5: Open the pull request

1. GitHub shows your change. Click the green **Create pull request**
   button.
2. Click **Create pull request** again.

{/* IMAGE NEEDED: images/Contributing/first-pr/create-pull-request.png
    Show: the pull request form with Create pull request circled.
    Device: computer. */}

---

## Done when

Your pull request is open, with your name on it. 🎉

You do not need to post it anywhere. The maintainers are notified on
GitHub when you open it.

---

## What happens next

Someone from the Projects & Tech team reviews it and merges it. Your
file then sits in the folder next to everyone else's.

They may ask for a small change. That is normal, not criticism. To make
it: open your pull request, click **Files changed**, click the **⋯** at
the top right of your file, choose **Edit file**, change it, and click
**Commit changes...**. It joins the same pull request.

No word after a few days? Ask in **#ask-for-help** with the link.

---

## Stuck?

- **No "Add file" button?** Make sure you are signed in to GitHub and
  inside the `contributors` folder. On a phone, try the desktop site.
- **GitHub says the file already exists?** Someone already used that
  name. Check that you typed your own username.
- **Anything else?** Ask in **#ask-for-help**. Say what you tried and
  what you saw.
