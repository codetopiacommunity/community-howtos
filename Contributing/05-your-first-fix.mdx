# Your First Fix

A real change to a real project, reviewed and merged. About **fifteen
minutes**, all in your browser. Nothing to install.

> [!NOTE]
> Words you will see on screen:
>
> - **Repository** (repo): a project's folder of files on GitHub.
> - **Issue**: a note saying something is wrong.
> - **Fork**: your own copy of a repo. Changing it cannot break the
>   original.
> - **Commit**: a saved change with a short note.
> - **Pull request** (PR): "here is my change, please review it."

---

## Before you start

You need a **GitHub account**, and you need to be signed in. Your
profile picture at the top right of any GitHub page means you are.

<a href="https://github.com/signup" target="_blank" rel="noopener noreferrer">🔗 Create a GitHub account</a>

---

## Step 1: Pick an issue

<a href="https://github.com/codetopiacommunity/open-source-practice/issues" target="_blank" rel="noopener noreferrer">🔗 Open the issues list</a>

1. Click any title to open it.
2. Note the **file name** it mentions (like `docs/about.md`) and the
   **issue number** next to the title (like `#1`).
3. Scroll to the bottom, type **"I'd like to take this one"** in the
   comment box, and click **Comment**.

## Step 2: Open the file

1. Click **open-source-practice** at the top of the page to go to the
   repo's front page.
2. Click the folder from the file name, for example `docs`.
3. Click the file, for example `about.md`.

{/* IMAGE NEEDED: images/Contributing/first-fix/open-the-file.png
    Show: the repo front page with the docs folder circled, then the
    file open. Device: computer. */}

---

## Step 3: Edit it

1. Click the **pencil icon** at the top right of the file.
2. GitHub says **"You need to fork this repository to propose
   changes."** That is expected. Click **Fork this repository**.
3. The file opens in an editor. Make the change the issue asked for.
   Nothing else.

## Step 4: Save it

1. Click the green **Commit changes...** button at the top right.
2. In **Commit message**, write what you did: "Fix typo in
   docs/about.md".
3. Click **Propose changes**.

{/* IMAGE NEEDED: images/Contributing/first-fix/commit.png
    Show: the Commit changes pop-up with a message typed and Propose
    changes circled. Device: computer. */}

---

## Step 5: Open the pull request

1. Click the green **Create pull request** button.
2. In the description box, type `Closes #1`, using your issue number.
3. Click **Create pull request** again.

{/* IMAGE NEEDED: images/Contributing/first-fix/pull-request.png
    Show: the PR form with "Closes #1" typed and Create pull request
    circled. Device: computer. */}

---

## Done when

Your pull request is open, with your name on it and `Closes #` in the
description. 🎉

Post the link in **#github-discussions** so a reviewer sees it.

---

## What happens next

Someone reviews it within a day or two. They may ask for a small
change. That is normal, not criticism.

To make it: open your pull request, click **Files changed**, click the
**⋯** at the top right of your file, choose **Edit file**, change it,
and click **Commit changes...**. It joins the same pull request.

---

## Stuck?

- **No pencil icon?** Open the file itself, not its folder.
- **Someone already claimed it?** Pick another issue.
- **Anything else?** Ask in **#general**. Say what you tried and what
  you saw.
